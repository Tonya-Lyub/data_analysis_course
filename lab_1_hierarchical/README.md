# Лабораторная работа №1: Иерархический кластерный анализ
**Выполнила:** Любецкая Антонина (563908, tonya1910200479@gmail.com)

## Описание проекта
Проведена иерархическая кластеризация 48 городов мира на основе датасета "Economics of Cities" (показатели: Work, Price, Salary). Предобработка включала замену строковых заглушек, конвертацию типов и масштабирование `StandardScaler`.

## Ключевые результаты
Для кластеризации применялся алгоритм агломеративной кластеризации (метод Уорда, евклидово расстояние). На основе анализа дендрограммы и графика каменистой осыпи выбрано разбиение на 3 кластера:
1. **Города тяжелого труда:** максимум рабочих часов при минимальной зарплате.
2. **Доступные рынки:** самые низкие цены при средних зарплатах и рабочих часах.
3. **Высокий уровень жизни:** максимальные зарплаты и цены, минимум рабочих часов.
Выбросов в виде единичных кластеров не обнаружено.
