# Задача: Лабораторная работа №3 — Кластерный анализ методом DBSCAN

## Контекст и цель
Выполнение третьей лабораторной работы по курсу «Анализ данных на Python» на датасете `Econom_Cities_data.csv` (48 городов мира, признаки: `Work`, `Price`, `Salary`). Требовалось обосновать выбор параметров `eps` и `min_samples`, провести кластеризацию `DBSCAN`, визуализировать разбиение на графиках рассеяния, интерпретировать кластеры и детально разобрать объекты, отнесённые к шуму (`-1`).

## Ключевые решения и реализация
- **Файл ноутбука:** [3_dz.ipynb](file:///c:/Users/tonya/data_analysis_course/lab_1_hierarchical/3_dz.ipynb)
- **Подбор параметров:** По правилу размерности ($D=3 \Rightarrow min\_samples \in [4; 6]$) и графику k-расстояний (`k-distance plot` через `NearestNeighbors`) определён порог перегиба `eps = 0.75` при `min_samples = 5`. Написана функция `evaluate_dbscan_grid(X, eps_values, min_samples_values)` для сравнения комбинаций по числу кластеров, проценту шума и метрике `silhouette_score` (0.460 без учёта шума).
- **Аналог центроидов для DBSCAN:** Вместо геометрических центроидов `k-means` реализована разметка точек по плотностным ролям (`Point_Type`): **Ядро (Core)** через `dbscan.core_sample_indices_`, **Граница (Border)** и **Шум (Noise, -1)**.
- **Визуализация:** Построены 3D Scatter Plot (в исходных признаках с подписями городов-выбросов) и 2D PCA Scatter Plot (где ядра отображены крупными кругами, границы — треугольниками, а шум — красными крестиками `X`).
- **Аналитика шума:** Все 12 городов шума разбиты на 4 смысловые группы (сверхбогатые `Zurich`, `Geneva`; ультра-дорогие `Oslo`, `Helsinki`, `Tokyo`, `Stockholm`; много работающие развитые `Los_Angeles`, `Taipei`; экстремумы переработок/дешевизны `Hong_Kong`, `Manila`, `Bombay` и артефакт медианного заполнения пропусков `Cairo`).
